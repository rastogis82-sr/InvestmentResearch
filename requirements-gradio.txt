# latest" rule as the Dockerfiles. An earlier unpinned `gradio>=4.0.0`

# panel: newer Gradio versions require gr.Chatbot's messages in the
# {"role", "content"} dict format, not the older [user, bot] tuple-pairs

# format (type="messages"), and the version is pinned so a future
# `pip install` can't silently jump to a different major release again.
